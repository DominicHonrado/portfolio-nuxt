# Dominic Honrado Portfolio

A Nuxt migration of the original static portfolio. It retains the original page content, Tailwind utility styling, fonts, imagery, responsive navigation, reveal animations, and certificate preview modal.

## Development

```bash
npm ci
npm run dev
```

## Production

```bash
npm run build
npm run preview
```

To generate a static site, run `npm run generate`. The portfolio pages are `/`, `/about`, `/skills`, `/certifications`, and `/contact`. The previous `.html` page URLs redirect to their Nuxt routes.
